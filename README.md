# Alabanza Ministerio Jerico - PWA

Esta carpeta contiene el código fuente completo de la aplicación web progresiva (PWA) para generar los anuncios semanales.

## Archivos incluidos:
- `index.html`: La aplicación principal. Contiene toda la estructura, estilos (Tailwind CSS) y lógica (JavaScript).
- `manifest.webmanifest`: Archivo de configuración que permite instalar la aplicación en Android.
- `sw.js`: Service Worker que permite a la aplicación funcionar de manera óptima e instalarse como PWA.
- `README.md`: Estas instrucciones.

## Instrucciones de despliegue en GitHub Pages:
1. Sube todos estos archivos a un repositorio nuevo en tu cuenta de GitHub.
2. Asegúrate de subir el logo real llamado **`7007.png`** a la misma carpeta (junto al index.html) para que se muestre automáticamente en la aplicación.
3. En tu repositorio de GitHub, ve a **Settings** (Configuración) > **Pages** (Páginas).
4. En **Build and deployment**, selecciona la rama `main` y guarda.
5. GitHub generará un enlace (ej: `https://tu-usuario.github.io/tu-repo/`).

## Instalación en Android:
1. Abre el enlace proporcionado por GitHub Pages en Google Chrome en tu teléfono Android.
2. Toca el menú de los tres puntos de Chrome (arriba a la derecha).
3. Selecciona **Instalar aplicación** o **Agregar a la pantalla principal**.
4. ¡Listo! La aplicación aparecerá en tu teléfono y funcionará con almacenamiento local sin depender del internet.
